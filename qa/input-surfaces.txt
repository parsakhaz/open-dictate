Dictate interactive-surface audit — 2026-10-21

Scope: app-owned controls, native windows, keyboard dispatch, dismissal and focus.
Acceptance: ordinary native input for every actionable surface; semantic controls;
visible focus; reachable close paths. Passive overlays may ignore mouse input.

Shared policy
- Cards, history picker and sheets are opaque, focusable native BrowserWindows.
  No actionable window uses setIgnoreMouseEvents, setShape or a mouse-event relay.
- Settings/welcome use a normal focusable native window with native close chrome.
- History uses normal focused input on Windows too: no hook capture or forwarded
  picker keystrokes. It retains the original target and restores it before paste.
- Button helper defaults type=button. Theme provides visible keyboard focus;
  hidden checkbox/radio inputs show focus on their visible track/dot.
- Sheet and picker command handlers defer to native control activation and Tab.
- Sheet, picker and settings geometry fits small work areas; content scrolls.

Checks
- Typecheck, lint, full unit suite, build and offscreen renderer/IPC harness.
- Geometry tests cover small/offset work areas; window-policy tests enforce
  normal interactive ownership and small settings bounds.
- Harness uses isolated profile and offscreen windows, emulated page focus and
  protocol keyboard input. It does not move the OS pointer or show desktop cards.
- Installed bundle/output hashes, healthy normal startup and direct status are
  verified separately in the installation report. Profile/history/model hashes
  are compared before and after local installation.

Limits / final acceptance
This audit is not a blanket guarantee of all native interactions. Physical first
clicks, real tray use, multi-monitor/mixed-DPI transitions, native Alt+F4 on docked
peek, screen-reader usability, physical microphones, real speech and cross-app
paste require manual/platform verification. No normal-profile test card is
created by this audit. Root/user coordinate the one stable installed-app manual
test. Keep PR37 unmerged until that confirmation; no version bump or release.
